# Decision Tree Classification

This project demonstrates the use of Decision Tree algorithms for classification problems.

## Projects

- Salary classification based on company, job and degree.
- Titanic passenger survival classification.

## Files

- `decision_tree_classification.ipynb` - Jupyter Notebook containing the models and analysis.
- `salaries.csv` - Dataset used for salary classification.
- `titanic.csv` - Dataset used for Titanic survival classification.

## Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib
