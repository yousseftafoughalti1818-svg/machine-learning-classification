# Naive Bayes Classification

This project demonstrates the use of Naive Bayes algorithms for different classification problems.

## Projects

- Titanic survival prediction using Gaussian Naive Bayes.
- Spam message detection using Multinomial Naive Bayes and CountVectorizer.

## Files

- `naive_bayes_classification.ipynb` - Jupyter Notebook containing the models and analysis.
- `titanic.csv` - Dataset used for Titanic survival prediction.
- `spam.csv` - Dataset used for spam classification.

## Technologies

- Python
- Pandas
- Scikit-learn
- CountVectorizer
- Naive Bayes
