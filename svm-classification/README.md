# Support Vector Machine (SVM) Classification

This project demonstrates the use of Support Vector Machines for multiclass classification.

## Projects

- Iris flower classification.
- Handwritten digit classification using the Scikit-learn Digits dataset.

## Files

- `svm_classification.ipynb` - Jupyter Notebook containing data visualization, model training and evaluation.

## Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Support Vector Machine (SVM)
